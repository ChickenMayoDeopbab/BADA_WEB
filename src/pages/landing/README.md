# BADA — 망설임에서, 첫마디로

조사 및 구현: 2026-10-20. 기존의 초록 배경 + 휴대폰 3개 히어로, 반복 카드, 네 가지 기능 탭 구조를 교체했다.

## 서비스에서 출발한 콘셉트

BADA의 목적은 통화 전 긴장을 느끼는 사용자가 AI와 안전하게 연습하고 자기 속도로 실제 통화를 준비하도록 돕는 것이다. 시나리오·성향·난이도 선택, 실시간 AI 통화와 스크립트, 통화 기록과 구간별 피드백, 자가진단, 워밍업, 커뮤니티를 기존 서비스 라우트에 연결한다. 진단 효과나 사용자 수·성공률처럼 검증되지 않은 수치는 추가하지 않는다.

하나의 **음성 선**을 공통 모티프로 사용한다. 히어로의 불규칙한 선이 스크롤하며 잔잔해지고, 다음 장면의 원과 리포트의 파형으로 이어진다. BADA 그린·기존 Pretendard·검정과 흰색을 유지하며, 큰 크기 대비·비대칭 들여쓰기·얇은 구획선으로 브랜드 편집물의 인상을 만든다.

## 장면과 인터랙션

1. **브랜드 포스터:** 비대칭 대형 타이포, 한 장의 앱 프리뷰, 초록 음성 선과 원형 시작 버튼. 줄 단위 마스크 진입, 스크롤 기반 파형 변형과 제품 시차.
2. **마음의 준비:** 검정 바탕의 문장에 초록색이 채워지고 원의 윤곽이 그려진다. 원문 제목은 항상 읽을 수 있다.
3. **한 통의 흐름:** Heddy의 이동형 목업 연출을 참고해 하나의 기기 프레임이 우 → 좌 → 우로 움직인다. 스크롤에 연결된 원근 회전과 내부 화면 전환으로 통화 전(상황 선택) → 통화 중(스크립트) → 통화 후(리포트)를 연결한다. 각 화면의 해당 영역을 초록 테두리와 주석으로 짚는다. 기기가 글 영역을 지날 때는 설명을 비워 겹침을 피한다. 직접 선택과 방향키·Home·End를 지원한다.
4. **통화 스튜디오:** 상황 선택, 다음 대화, 피드백 전환을 직접 조작한다. 마이크·API·실제 통화는 시작하지 않는다.
5. **일상:** 큰 30초 워밍업, 자가진단, 사진의 마스크 확장과 시차, 커뮤니티. 각 구도를 다르게 구성한다.
6. **마무리:** FAQ, 스토어 동선, 큰 BADA 워드마크와 기존 공개 정책·공식 채널·운영 정보.

## 구현과 검증 기준

- GSAP / ScrollTrigger는 랜딩 진입 시 동적 import한다. 브라우저 기본 스크롤을 유지하고 스크롤 잠금이나 강제 스냅을 사용하지 않는다.
- `gsap.matchMedia`와 React effect 정리로 모션 선호도 변경·라우트 이동 시 애니메이션을 복원·제거한다. 폰트 로드 후 스크롤 좌표를 갱신한다.
- 모션 줄이기에서는 마스크·시차·파형 변형과 긴 고정 구간을 제거한다. 모바일·짧은 화면에서는 일반 흐름의 제품 선택 UI를 제공한다.
- 주요 정보는 애니메이션의 성공 여부와 관계없이 DOM에 남고, 스크린리더용 제목과 버튼 이름을 유지한다. 모양을 위한 복제 문장은 접근성 트리에서 제외한다.
- 색상·타이포·반경은 기존 디자인 시스템을 사용한다. 큰 포스터·워드마크 타입 두 가지는 TypeScript와 Tailwind 토큰에 함께 추가한다.
- 앱스토어·원스토어 주소는 미확정 상태를 유지한다. 주소를 추정하거나 가짜 다운로드 동작을 넣지 않는다.

## 이동형 목업 레퍼런스 추가

[Heddy](https://www.heddy.site/)를 직접 스크롤하며 기기 프레임과 내부 화면이 장면 사이에서 이어지고, 기록·분석·추천에 맞춰 주변 내용이 변하는 방식을 확인했다. 렌더링된 DOM에서도 `perspective`, `translate3d`, `rotateX`, `rotateZ` 조합과 화면 내부의 이동 요소가 확인된다. 특정 3D 엔진을 사용한다고 단정하지 않고, BADA에서는 기존 GSAP / ScrollTrigger와 CSS 원근 변환으로 구현한다.

폰의 위치와 회전은 시간 반복이 아니라 하나의 스크롤 타임라인에 연결되며, 역방향 스크롤과 창 크기 변경에도 위치를 다시 계산한다. 모바일·짧은 화면·모션 줄이기에서는 이동과 회전을 정리하고 같은 화면·주석을 직접 선택해 읽을 수 있다.
