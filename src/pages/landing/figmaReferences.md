## 구현 출처와 경계

- 훈련 설정 `3765:2869`: 초기에는 별도 미리보기로 구현했으나 사용자 피드백에 따라 섹션·목업·전용 에셋을 제거했다. 실제 웹 서비스의 훈련 설정 기능은 유지한다.
- 통화 도움: 세 개의 스크립트 하위 프레임에 대해 각각 디자인 컨텍스트와 스크린샷을 확인했다. 개인 프로필 사진이 포함된 전체 통화 화면으로 교체하지 않고, 기존 피자 주문 화면의 스크립트 슬롯에 해당 컴포넌트를 배치한다. 기존 도움말·구분선 SVG를 재사용한다.
- 진단 결과 `4966:5319`: 화면 전체의 고정된 예시 결과를 붙이지 않는다. 기존 공개 진단 패널 안에 가운데 정렬 구성과 원본 구분선 에셋을 옮기고 로컬 자가진단의 결과와 기존 다시 시작·앱 다운로드 동선을 연결한다. 레벨 설명은 도움말 대신 결과 본문에 표시한다.
- 미리보기에서 훈련·예약·저장 요청은 발생하지 않는다. 실제 기능 실행은 기존 웹 시작 경로에서 제공한다. 랜딩의 자가진단은 문항 조회·제출도 서버에 요청하지 않고 브라우저 안에서 끝낸다.
- 저장한 것은 원본 SVG 에셋뿐이며 전체 디자인 스크린샷이나 임시 Figma URL을 런타임 이미지로 쓰지 않는다.
